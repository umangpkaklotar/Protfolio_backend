# Project Features

### 1. PCB AI Defect Inspection System Features
- **Custom YOLOv8 Model**: Detects 7 distinct PCB defect classes with >77% to 92% confidence:
  1. *Copper*: Unwanted, excess, or stray copper causing bridging risks.
  2. *Mousebite*: Edge defects, breakaway perforations, rough tears along perimeter.
  3. *Open*: Open-circuit traces with broken signal conductivity.
  4. *Pin-hole*: Microscopic voids or air bubbles in conductive copper or solder mask.
  5. *Short*: Unintended conductive bridges crossing between traces.
  6. *Spur*: Pointed copper protrusions extending outward from tracks.
  7. *Missing Hole*: Unpunched pin-through holes or blocked vias.
- **Multi-Surface Optical Inspection**: Supports high-resolution desktop uploads and live shop-floor mobile camera streams via HTML5 Web Camera API.
- **Instant Bounding Boxes & Telemetry**: Renders localized colored bounding boxes, defect labels, confidence percentages, and total defect counts in milliseconds.
- **Automated Industrial Quality Decisions**:
  - *PASS*: Zero defects detected; boards advance to packaging/assembly.
  - *FAIL / REWORK*: Critical or medium defects detected; routed to technician station with rework actions.
  - *REVIEW*: Borderline confidence or lighting anomalies routed to operator verification queue.
- **ROS 2 & Gazebo Digital Twin**: Virtual automated conveyor factory line in Gazebo Sim 8 with ROS 2 nodes, virtual proximity sensors, and virtual camera feeds.
- **Sequential 1-by-1 Logic**: Proximity sensor trips when PCB enters inspection station, pauses conveyor, captures 640x480 frame at 10 FPS, executes YOLOv8 inference, publishes decision to RViz2, and releases conveyor upon `/pcb/inspection_done`.
- **Full Traceability**: MongoDB records unique PCB ID, Inspection ID, Machine ID, Camera ID, defect coordinates, timestamps, and quality decisions for historical auditing.

### 2. Document AI (Enterprise RAG) Features
- **Multi-Format Ingestion**: Supports PDF (page-aware), Word DOCX (table-aware), CSV (batch/tabular), Markdown, and TXT files.
- **Semantic Overlap Chunking**: Chunks text into 900-character segments with 150-character overlap to prevent boundary context loss.
- **Sub-Millisecond Vector Retrieval**: Chunks are embedded in batches of 32 with Gemini Embedding-2, L2-normalized, and indexed in in-memory FAISS IndexFlatIP. Top-K search executes in sub-milliseconds.
- **Low-Latency Streaming**: Streams answer tokens live to the browser via Server-Sent Events (SSE) using Groq LPU inference.
- **Verified Citation Bubbles**: Transparent citations reference exact source filename and page/section number with zero fabricated document IDs.
- **Strict Anti-Hallucination Guardrails**: Model temperature locked at 0.2 with negative prompts: answers strictly using provided excerpts or states "The answer was not found in the uploaded documents."
- **Multi-Tenant User Isolation**: Clerk JWT authentication isolates each user's in-memory vector index space and encrypted MongoDB chat histories.

### 3. AI Code Converter Features
- Real-time syntax translation between Python, JavaScript, TypeScript, and C++.
- Interactive web interface with side-by-side code diff previews.
- Automated syntax validation ensuring code structures are maintained without loss.
